## 구성

9개 씬 · 18컷 · 편집 목표 90초. 인물·동물 5장, 의상 3장, 기존 소품 5장, 장소 2장, 모시 수건 1장, 씬별 키 이미지 9장으로 **총 25장**의 PNG가 있습니다. 씬 이미지는 1024×576, 나머지 참고 이미지는 1024×1024입니다.

콘티 v2에는 컷 영상 18자리와 씬별 편집 영상 9자리, 이미지 다운로드, 프롬프트 복사, 동영상 선택·재생 기능이 있습니다. 원본 HTML v1과 엑셀 v1도 이전 버전으로 보관합니다.

## 반영한 연출 수정

- 뜨거운 감자 세 개는 **하얀 모시 수건**에 싸서 건네고 거둡니다.
- S04 인물은 발을 안정적으로 디딘 자연스러운 자세를 유지합니다.
- 닭의 직접적인 타격·상처는 보여주지 않고 화면 밖 사건과 반응으로 전달합니다.
- 대사·내레이션·음악·제목은 후반 편집을 기준으로 준비했습니다.

## Flow 영상 상태

2026-11-07 작업 기록 기준, S01~S07은 Flow에서 생성 완료 표시를 확인했습니다. S08은 비정상적인 활동 감지 오류로 실패했고, S09는 미제출입니다. **MP4 다운로드와 전체 재생 검수는 하지 않았으며, 이 저장소에 실제 생성 영상은 포함되지 않습니다.**

각 씬 8초 생성 원본은 90초 편집 완성본과 다릅니다. 7개 생성 완료 표시만으로 총 재생 길이나 최종 편집 완료를 의미하지 않습니다.

공개본의 경로는 상대 경로로 정리했습니다. 컴퓨터 유즈로 업로드할 때에는 내려받은 폴더에서 해당 PNG를 선택하거나 현재 PC의 실제 경로를 지정하세요. 로컬 동영상 선택은 현재 페이지에서만 유지되며, 다시 열 때 재선택하거나 HTML 옆 `videos` 폴더에 안내된 이름으로 저장해 연결합니다.
