## 구성

9개 씬 · 18컷 · 편집 목표 90초. 인물·동물 5장, 의상 3장, 기존 소품 5장, 장소 2장, 모시 수건 1장, 씬별 키 이미지 9장으로 **총 25장**의 PNG가 있습니다. 씬 이미지는 1024×576, 나머지 참고 이미지는 1024×1024입니다.

콘티 v2에는 컷 영상 18자리와 씬별 편집 영상 9자리, 이미지 다운로드, 프롬프트 복사, 동영상 선택·재생 기능이 있습니다. 원본 HTML v1과 엑셀 v1도 이전 버전으로 보관합니다.

## 반영한 연출 수정

- 뜨거운 감자 세 개는 **하얀 모시 수건**에 싸서 건네고 거둡니다.
- S04 인물은 발을 안정적으로 디딘 자연스러운 자세를 유지합니다.
- 닭의 직접적인 타격·상처는 보여주지 않고 화면 밖 사건과 반응으로 전달합니다.
- 대사·내레이션·음악·제목은 후반 편집을 기준으로 준비했습니다.

## Flow 영상 상태

사용자가 제공한 **MP4 9개**를 [동영상 폴더](제작자료/이미지/동영상)에 업로드했습니다. S04 파일 번호를 정정했고, 소년이 수탉을 안고 있는 S05 영상을 추가했습니다. 씬별 대응은 [제작 현황](제작현황.md)을 참고하세요.

각 영상은 약 8초인 생성 원본입니다. 이 영상들을 이은 72초 편집본에 내레이션·자막·배경음악을 합성했으며, 90초 완성본 편집과 제목 편집, 전체 시청 검수는 남아 있습니다.

공개본의 경로는 상대 경로입니다. 업로드할 때는 현재 PC에 내려받은 파일을 선택하세요. HTML 콘티의 동영상 선택은 현재 페이지에서만 유지되며, 자동 연결은 아직 적용하지 않았습니다.
